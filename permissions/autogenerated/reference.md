## Default Permission

Default permissions for the PencilKit plugin.
Allows setting active state, configuring tools, and clearing drawing.

#### This default permission set includes the following:

- `allow-is-available`
- `allow-set-active`
- `allow-set-tool`
- `allow-clear`
- `allow-set-excluded-rects`
- `allow-configure-tools`
- `allow-sync-undo-redo`
- `allow-register-listener`
- `allow-remove-listener`
